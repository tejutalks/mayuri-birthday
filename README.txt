MAYURI AKKA — STEP-BY-STEP BIRTHDAY EXPERIENCE

Open index.html in a browser to test. Each surprise is a separate screen. The next screen stays hidden until the current interaction is completed and its button becomes available.

Includes animated transitions, floating hearts, photo polaroids, six poppable balloons, a personal nickname question (accepts Anya/anya/anyya, including harmless punctuation/spaces), a scratch card, an animated letter envelope, and a layered music-box-style birthday melody.

Music tries to autoplay. Browsers—especially on phones—often block sound until the visitor interacts, so the tune starts on the first tap/key press if autoplay is blocked. The Play/Pause button remains available.

Photos: the picker previews photos on the current device only. To share photos with Mayuri Akka, upload image files with the site and reference them in the memory stage.

Publish free using GitHub Pages:
1. Create a public repository named mayuri-birthday at https://github.com.
2. Upload index.html and any image files.
3. Open Settings → Pages.
4. Select Deploy from a branch, branch main, folder /(root), and Save.
5. Wait for the URL, usually https://YOUR-USERNAME.github.io/mayuri-birthday/
6. Test the link on your phone before sending.
